# mm3d-engine

Fork de [TriAevum-Switch](https://github.com/JohnUzoka/TriAevum-Switch), a su vez fork de
[TriAevum](https://github.com/coccofresco/TriAevum) (coccofresco), con el objetivo de recompilar
*The Legend of Zelda: Majora's Mask 3D* de forma nativa (AOT) para PC y Nintendo Switch.

## Licencia y atribución

- El código original conserva su licencia: **GPL-3.0-or-later** (ver `LICENSE` y `LICENSE_SCOPE.md`).
  Los avisos de copyright, `THIRD_PARTY_NOTICES.md` y `LICENSES/` del upstream se mantienen sin cambios.
- Las modificaciones de este fork también se publican bajo GPL-3.0-or-later.
- Material excluido, igual que en el upstream: **no** se incluyen ROMs, CIAs, claves, código ni assets de Nintendo,
  ni C++ generado a partir del juego. Cada usuario debe usar su propio dump.
- El módulo iMMERSE/MXAO del upstream tiene licencia propia (no GPL); no se usa ni se amplía aquí.
- Project Restoration (GPL-2.0, sin "or later") se usa solo como referencia de hechos; no se copia su código.
- 3dsrecomp (MIT) puede reutilizarse conservando su aviso de licencia.
